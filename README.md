# Poll Voting App

A web-based poll voting system where users can create accounts, vote on polls, and view real-time poll results.

## Features

- User authentication (Signup/Login)
- Role-based admin access
- Create and manage polls
- Vote on polls
- Real-time poll results
- State-based result filtering
- Responsive design
